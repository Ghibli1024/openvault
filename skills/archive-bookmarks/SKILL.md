# Archive Bookmarks

Use this wrapper when the user wants to import a bookmark-style HTML export into Obsidian from the plugin entry layer.

## Handoff Target

The canonical execution workflow now lives in this repository at:

- `../bookmarks/SKILL.md`

Open that skill and follow its current intake, execution, and validation rules.

## Preserve These Behaviors

- keep the existing categories-only archive structure
- keep the current taxonomy precedence rules
- preserve established local `ROOT分类目录.md` files on merge flows
- do not convert this source into the managed archive root layout used by `小红书`, `B站`, or `X Likes`

Read `../../references/taxonomy-policy.md` before merging into an existing archive.
